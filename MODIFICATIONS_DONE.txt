v11 FIXES (latest)
═══════════════════════════════════════════

FIX 1 — Admin Login (smarthub.sql)
  Problem: Admin password hash in SQL was bcrypt hash of "password"
           (Laravel default), NOT "admin123" — so login always failed.
  Fix: Replaced with correct bcrypt hash for "admin123".
       Also added ON DUPLICATE KEY UPDATE so re-importing fixes
       an existing database without needing to delete the user manually.

FIX 2 — Add to Cart / Buy Now not working (main.js)
  Problem: Products loaded from DB have string IDs (e.g. "1"), but
           onclick passes a number (e.g. 1). Strict === comparison
           caused allProducts.find() to always return undefined,
           so Add to Cart and Buy Now silently did nothing.
  Fix: Changed === to == (loose equality) in:
       - addToCart()        → find product & find existing cart item
       - viewProductDetail() → find product for detail modal
       - removeFromCart()   → filter cart items
